# Guía de Administración de WordPress con WP-CLI

## 1. Utilidad y Casos de Uso Real de WP-CLI

**WP-CLI** es la interfaz de línea de comandos oficial para administrar WordPress directamente desde la terminal del servidor.

### ¿Por qué es útil?

* **Velocidad y eficiencia:** Permite realizar tareas repetitivas en segundos (por ejemplo, actualizar todos los plugins con un solo comando).
* **Automatización:** Facilita la creación de scripts para tareas de mantenimiento, respaldos y despliegues automáticos.
* **Recuperación ante desastres:** Si un plugin o error bloquea el panel de administración (`/wp-admin`), permite desactivar complementos o solucionar problemas directamente por la terminal sin perder el acceso.

### ¿Se utiliza realmente en la administración profesional?

**Sí, de forma masiva.** Es un estándar de la industria por las siguientes razones:

1. **Proveedores de hosting:** Viene integrado en la mayoría de los alojamientos web especializados en WordPress.
2. **Entornos DevOps:** Es fundamental en flujos de trabajo modernos (Docker, CI/CD) para instalaciones y despliegues automatizados.
3. **Migraciones seguras:** Su comando de búsqueda y reemplazo de datos (`search-replace`) maneja la base de datos de forma segura sin romper la serialización.

## 2. Instalación de WP-CLI en el servidor LAMP

Descargamos el archivo `wp-cli.phar` del repositorio oficial de WP-CLI. Los archivos `.phar` son similares a los archivos `.jar` de Java; se utilizan para empaquetar y distribuir aplicaciones o librerías de PHP en un único archivo ejecutable. *Puede consultar el listado completo y la [documentación oficial de WP-CLI en su sitio web](https://developer.wordpress.org/cli/commands/){:target="_blank" rel="noopener noreferrer"}.*

```bash
curl -O https://raw.githubusercontent.com/wp-cli/builds/gh-pages/phar/wp-cli.phar

```

Le asignamos permisos de ejecución al archivo descargado:

```bash
chmod +x wp-cli.phar

```

Movemos el archivo al directorio global `/usr/local/bin/` renombrándolo como `wp` para poder utilizarlo directamente desde cualquier ruta sin necesidad de escribir su ubicación completa:

```bash
sudo mv wp-cli.phar /usr/local/bin/wp

```

Una vez realizado este paso, podemos hacer uso de la utilidad desde la línea de comandos. Si escribimos `wp` en la terminal, nos deberá mostrar la página de ayuda del comando:

```bash
wp

```

## 3. Gestión Avanzada y Mantenimiento desde la Terminal

A continuación, se muestra un pequeño resumen de algunos de los comandos principales que podemos utilizar con WP-CLI. *Puede consultar los detalles de cada comando y parámetros adicionales en el [Manual Oficial de WP-CLI](https://make.wordpress.org/cli/handbook/){:target="_blank" rel="noopener noreferrer"}.*

### 3.1 Actualización de los plugins a la última versión

```bash
wp plugin update --all

```

### 3.2 Actualización de los themes a la última versión

```bash
wp theme update --all

```

### 3.3 Comprobar la versión del core de WordPress

```bash
wp core check-update

```

### 3.4 Actualizar el core de WordPress a la última versión

```bash
wp core update

```

### 3.5 Cambiar el idioma de WordPress

Podemos listar los idiomas disponibles para WordPress ejecutando:

```bash
wp language core list

```

Una vez que hemos encontrado el nombre del idioma, podemos instalarlo y activarlo con el siguiente comando:

```bash
wp language core install en_US --activate

```

### 3.6 Listar los plugins instalados

```bash
wp plugin list

```

### 3.7 Instalar y activar un plugin

Para instalar y activar un plugin (por ejemplo, `wps-hide-login`), ejecutaríamos el siguiente comando:

```bash
wp plugin install wps-hide-login --activate

```

### 3.8 Configurar un plugin

Para configurar el nombre de la nueva URL que vamos a utilizar con el plugin `wps-hide-login`, ejecutaríamos:

```bash
wp option update whl_page "nombre_secreto" --path=/var/www/html --allow-root

```

### 3.9 Desactivar un plugin

Para desactivar un plugin concreto:

```bash
wp plugin deactivate wps-hide-login

```

### 3.10 Eliminar un plugin

Para eliminar el plugin por completo de la instalación:

```bash
wp plugin delete wps-hide-login

```

### 3.11 Eliminar los plugins que están inactivos

```bash
wp plugin delete $(wp plugin list --status=inactive --field=name)

```

### 3.12 Listar los themes instalados

```bash
wp theme list

```

### 3.13 Instalar y activar un theme

Para instalar y activar un tema (por ejemplo, `mindscape`):

```bash
wp theme install mindscape --activate

```

### 3.14 Activar un theme previamente instalado

Para cambiar a un tema que ya se encuentra descargado en el servidor:

```bash
wp theme activate twentytwenty

```

### 3.15 Eliminar un theme

Para borrar un tema específico:

```bash
wp theme delete mindscape

```

### 3.16 Eliminar los themes que están inactivos

```bash
wp theme delete $(wp theme list --status=inactive --field=name)

```
